# 🎮 GameHub

A full-stack web application for discovering and saving your favorite video games.

Built with **React** and **Supabase** as a final project for a React course.

---

## 🚀 Live Demo

🔗 [https://gamehub-dogus.vercel.app](https://gamehub-dogus.vercel.app)

---

## ✨ Features

- 🔍 **Game Search & Discovery** — Browse and search games with real-time filtering
- 🔐 **User Authentication** — Secure sign up / login powered by Supabase Auth
- ❤️ **Favorites** — Save and manage your favorite games per user account
- 🎮 **Game Detail Page** — Full info page for each game
- 💬 **Comments System** — Logged-in users can leave comments on games
- 📱 **Responsive Design** — Works on desktop and mobile

---

## 🛠️ Tech Stack

| Layer              | Technology            |
| ------------------ | --------------------- |
| Frontend           | React, React Router   |
| Backend / Database | Supabase (PostgreSQL) |
| Authentication     | Supabase Auth         |
| Styling            | CSS / Tailwind CSS    |
| Version Control    | Git & GitHub          |

## 🚀 Getting Started

```bash
git clone git@github.com:Dogusfoki/Rehactor--React-Final-Project.git
cd gamehub
npm install
npm run dev
```

Create a `.env` file with your Supabase credentials:

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_anon_key
```
